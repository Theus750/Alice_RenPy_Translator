Como Resolver Este Erro?

01
Selecionou uma subpasta?

Se você abriu diretamente uma subpasta como images/, audio/ ou a pasta do motor, suba um nível no explorador para selecionar a raiz onde a pasta game/ se encontra.

02
Projeto criado recentemente?

Certifique-se de ter criado o projeto no Ren'Py Launcher oficial antes de tentar a tradução. O iniciador cria automaticamente toda a hierarquia de pastas e templates obrigatórios necessários para a indexação.

Documentação oficial Ren'Py open_in_new
03
Abrir no Explorador

Abra a pasta inspecionada diretamente no explorador do Windows para verificar se os arquivos foram descompactados corretamente ou se estão corrompidos em outro diretório.
